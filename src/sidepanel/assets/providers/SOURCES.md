# Provider-logo assets

- `claude-mark.svg`: orange Claude mark path extracted without shape/color alteration from the inline ClaudeWordmark SVG on [Claude’s official website](https://claude.com/). Standalone SVG wrapper/viewBox added for use as a small provider icon. Color #D97757. Retrieved September 24, 2026.
- `openai-black.svg`, `openai-white.svg`: original monoblossom files from [OpenAI’s published logo archive](https://cdn.openai.com/brand/OpenAI-Logos-2025.zip), linked in the context of [OpenAI design guidelines](https://openai.com/brand/). File bytes are unchanged; filenames simplified for the bundle. Retrieved September 24, 2026.
